CronyGO Wllama C++ WASM
未DL
Wllama = llama.cpp(C++)をWASM化した爆速エンジン
Java/KotlinのNDKみたいに、C++の計算をWebで直接動かすイメージ
Github Pages対応: single-thread版でCOOP/COEPヘッダー不要
こんにちは！Wllama版CronyGOです。C++のWASMエンジンで動いてます。

Androidで例えると:
Java/Kotlin (UI) → JNI → C++ (llama.cpp) で計算
と同じで、
JS (UI) → WASM → C++ (llama.cpp) で計算してるよ。

モデルをDLして防災について聞いてみて。
エンジン: wllama 2.3.4 + llama.cpp (C++) → WASM single-thread
モデル: GGUF Q4_0量子化 (300MB) / キャッシュされると2回目は爆速
Github Pagesでも動くように useMultiThread: false にしてある (trueにすると更に速いがヘッダー設定が必要)
